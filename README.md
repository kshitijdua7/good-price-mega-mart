## Managing the store

The private owner dashboard allows the store owner to add products and photos, update prices and stock availability, review order requests, set delivery charges, manage offers and publish opening hours. Customer accounts do not have access to these controls.

The website records order requests; it does not collect payments online. Delivery charges can be confirmed individually for Ludhiana, the rest of Punjab and other states.
