# Good Price Mega Mart

Interactive showroom website built with Next.js, React and Tailwind CSS. Original implementation inspired by the Dusk visual direction; paid template source is not included.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository into Vercel, keep the Next.js framework preset and root directory, and deploy. No environment variables are required.

## Content

Edit categories and products in `app/store.tsx` and styling in `app/globals.css`. Product artwork is illustrative. Confirm exact inventory, prices, business contact details, warranty and offers with the store before a retail launch. The enquiry form opens a WhatsApp draft for the visitor to send; it does not store submissions.
